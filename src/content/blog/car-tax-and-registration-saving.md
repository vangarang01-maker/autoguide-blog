중고차 계약할 때 "차값 1,500만 원"만 보고 예산을 짜면 반드시 틀어집니다. **이전 비용으로 130만 원 안팎이 추가로 나가기 때문입니다.** 그런데 이 중 상당 부분은 아는 만큼 줄일 수 있습니다. 계산 구조부터 절약 포인트까지 순서대로 정리합니다.

## 1. 중고차 이전 시 실제로 나가는 돈

| 항목 | 성격 | 대략 금액(1,500만 원 차 기준) |
| --- | --- | --- |
| 취득세 | 세금(필수) | 약 105만 원 |
| 공채 매입/할인 | 준조세(즉시 매도 가능) | 약 5~25만 원 |
| 증지대·인지대 | 수수료(필수) | 약 1~2만 원 |
| 이전대행 수수료 | 선택 | 3~10만 원 |
| 자동차 보험 | 필수 | 별도 |
| 성능점검 보증 | 매매상사 부담 원칙 | 0원(청구받으면 확인) |

**세금 자체는 못 줄입니다. 줄일 수 있는 건 공채와 대행 수수료, 그리고 과세표준 적용 방식입니다.**

## 2. 취득세 계산 — 세율보다 '과세표준'이 중요합니다

### 세율

| 차종 | 취득세율 |
| --- | --- |
| 승용차(일반) | 7% |
| 경차(1,000cc 이하) | 4% (일정 금액 이하 면제) |
| 승합·화물차 | 5% |
| 영업용 | 4% |

### 과세표준이 결정되는 방식

여기가 핵심입니다. 취득세는 **실제 매매가격**과 **시가표준액** 중 **더 높은 쪽**을 기준으로 매깁니다.

- 매매상사를 통한 거래: 계약서상 신고가액이 기준이 되지만, 그 금액이 시가표준액보다 낮으면 **시가표준액**으로 과세됩니다.
- 개인 간 직거래: 마찬가지로 시가표준액이 하한선 역할을 합니다.

즉 **"계약서를 낮게 써서 세금을 줄이는" 방법은 시가표준액 아래로는 통하지 않습니다.** 무리하게 다운계약을 하면 세금은 그대로인데 탈세 문제만 생깁니다.

### 시가표준액 확인 방법

시가표준액은 **신차 출고가격 × 잔가율**로 산정됩니다. 잔가율은 경과 연수에 따라 정해진 표를 씁니다.

| 경과 연수 | 승용차 잔가율(대략) |
| --- | --- |
| 1년 | 0.681 |
| 2년 | 0.562 |
| 3년 | 0.472 |
| 4년 | 0.404 |
| 5년 | 0.340 |
| 6년 | 0.284 |
| 7년 | 0.240 |
| 8년 | 0.196 |
| 10년 | 0.132 |

**위택스(wetax.go.kr)에서 차량번호로 정확한 시가표준액을 미리 조회할 수 있습니다.** 계약 전에 반드시 조회하세요. 예산 오차를 없애는 가장 빠른 방법입니다.

### 실제 계산 예시

**사례 A** — 신차가 3,500만 원, 5년 경과, 실매매가 1,500만 원

- 시가표준액 = 3,500만 × 0.340 = **1,190만 원**
- 실매매가 1,500만 원 > 시가표준액 1,190만 원 → **1,500만 원이 과세표준**
- 취득세 = 1,500만 × 7% = **105만 원**

**사례 B** — 신차가 5,000만 원, 3년 경과, 실매매가 2,000만 원

- 시가표준액 = 5,000만 × 0.472 = **2,360만 원**
- 실매매가 2,000만 원 < 시가표준액 2,360만 원 → **2,360만 원이 과세표준**
- 취득세 = 2,360만 × 7% = **165만 원**

> **주의**: 사례 B처럼 감가가 심한 인기 없는 모델이나 사고 이력차는 **실제 산 가격보다 세금이 훨씬 많이 나옵니다.** 급매·사고차를 싸게 살 때 반드시 계산해 봐야 하는 부분입니다. 이 함정 때문에 "차는 800만 원인데 세금이 150만 원"인 상황이 실제로 생깁니다.

## 3. 공채 — 여기서 가장 많이 아낍니다

### 공채가 뭔가

자동차를 등록할 때 지자체가 발행하는 **지역개발채권(또는 도시철도채권)** 을 의무로 사야 합니다. 이건 세금이 아니라 **빌려주는 돈**입니다. 5~7년 뒤 이자와 함께 돌려받습니다.

### 두 가지 선택지

| 방식 | 설명 | 유리한 경우 |
| --- | --- | --- |
| **매입 후 보유** | 채권을 그대로 들고 만기까지 보유 | 여유자금 있고 만기 관리 가능 |
| **즉시 매도(할인)** | 사자마자 팔아 차액만 부담 | 대부분의 경우 |

**즉시 매도하면 채권 액면가의 대략 7~15%만 부담하고 끝납니다.** 예를 들어 공채 매입 의무액이 150만 원이고 할인율이 10%라면, 실제 지출은 15만 원입니다.

- 만기 보유는 5~7년간 150만 원이 묶이는 대신 이자를 받습니다.
- **금리 상황에 따라 유불리가 갈리지만, 현금 흐름을 생각하면 대부분 즉시 매도가 합리적입니다.**

### 공채 부담이 지역마다 다릅니다

공채 매입률은 **등록 지역(주소지) 기준**입니다.

- 서울·부산 등 대도시: 매입률이 높습니다.
- 일부 지방 소도시: 매입률이 낮거나 배기량 기준 면제 구간이 있습니다.

**단, 주소지를 옮겨 등록하는 건 실거주 요건과 맞아야 합니다.** 위장전입은 과태료 대상이니, 실제로 이사 계획이 있는 경우에만 순서를 조정하세요.

### 매입 면제 구간 확인

배기량 1,000cc 미만 경차, 일정 조건의 소형 화물차 등은 공채 매입이 면제되거나 대폭 축소됩니다. 경차의 매력이 여기서도 나옵니다.

## 4. 감면 대상 — 해당되면 크게 줍니다

### 취득세 감면

| 대상 | 감면 내용 |
| --- | --- |
| 하이브리드차 | 취득세 일정액 감면 |
| 전기차·수소차 | 취득세 대폭 감면 |
| 경차 | 일정 취득가액 이하 면제 |
| 장애인(본인 또는 세대원 공동명의) | 취득세·자동차세 면제 |
| 국가유공자 | 취득세·자동차세 면제 |
| 다자녀 가구(18세 미만 3인 이상) | 지자체별 감면 |

**감면 한도와 요건은 매년 세법 개정으로 바뀝니다.** 계약 전에 관할 구청 세무과 또는 위택스에서 당해 연도 기준을 반드시 확인하세요. 특히 다자녀 감면은 지자체 조례 사항이라 지역차가 큽니다.

### 장애인 감면의 실무 포인트

- 장애인 본인 명의 또는 **세대를 같이하는 배우자·직계존비속과의 공동명의**여야 합니다.
- 1가구 1대에 한합니다.
- 감면받은 차량은 **일정 기간 내 처분 시 감면세액이 추징**됩니다. 이 조건을 모르고 팔았다가 세금을 다시 내는 경우가 많습니다.

## 5. 이전대행 수수료 — 직접 하면 0원

매매상사에서 "이전대행비 10만 원"을 청구하는 경우가 많습니다. 이건 법정 수수료가 아니라 **서비스 요금**입니다.

### 직접 이전 절차 (차량등록사업소 방문, 약 1시간)

**준비물**

1. 자동차 양도증명서(매도인 인감 날인)
2. 매도인 인감증명서(자동차 매도용)
3. 자동차등록증
4. 매수인 신분증
5. 책임보험 가입 증명(가입 후 방문해야 합니다)
6. 도장(서명 가능한 경우 생략 가능)

**순서**

1. 보험 먼저 가입 → 2. 등록사업소에서 이전등록 신청서 작성 → 3. 취득세 고지서 발급·납부 → 4. 공채 매입/할인 → 5. 번호판 유지 또는 신규 발급 → 6. 등록증 수령

**절약 포인트**: 등록사업소 근처 대행업소는 3~5만 원 수준입니다. 상사 청구액이 8~10만 원이라면 **"직접 하겠다"고 말하는 것만으로 협상 여지가 생깁니다.**

## 6. 놓치기 쉬운 비용 3가지

### ① 자동차세 일할 정산

자동차세는 소유 기간에 따라 나뉩니다. **인수일 기준으로 매도인과 정산**해야 하는데, 이걸 안 챙기면 이미 낸 세금을 매도인이 그대로 가져갑니다. 계약서에 정산 조항을 넣으세요.

### ② 이전 지연 과태료

인수일로부터 **15일 이내** 이전등록 의무입니다. 초과하면 일자별로 과태료가 붙습니다. 매도인이 "천천히 하세요"라고 해도 본인 손해입니다.

### ③ 자동차 검사 시기

인수 직후 검사 기간이 도래하는 차량이 있습니다. **검사 유효기간을 등록증에서 확인**하고, 만료가 임박했다면 검사비와 부적합 시 정비비를 협상에 반영하세요.

## 7. 요약 — 절약 우선순위

1. **위택스에서 시가표준액 먼저 조회** → 예산 오차 제거. 특히 감가가 큰 차량은 세금이 차값의 10%를 넘을 수 있습니다.
2. **공채는 즉시 매도** → 액면가의 10% 내외만 부담.
3. **감면 대상 여부 확인** → 하이브리드·경차·다자녀·장애인. 해당되면 수십만 원.
4. **이전대행은 직접 또는 저가 대행** → 5만 원 절약.
5. **자동차세 일할 정산 명시** → 수만 원 절약.

세금은 못 줄여도 **부대비용은 충분히 줄일 수 있습니다.** 계약서에 도장 찍기 전에 이 다섯 가지만 확인하면 평균 30~50만 원, 감면 대상이라면 100만 원 이상 차이가 납니다. 차 자체를 고르는 기준은 [중고차 12가지 현장 점검표](/blog/used-car-inspection-checklist/)를 함께 보세요.
